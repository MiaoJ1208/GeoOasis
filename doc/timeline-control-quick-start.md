# 交通态势时间线控制条 - 快速开始

## 功能概览

时间线控制条是一个交互式UI组件，允许用户实时控制交通态势动画的播放、暂停和时间调节。

## UI 布局

```
┌─────────────────────────────────────────────────────┐
│  ⏸  [════════●════════]  2015-01-26T10:30:00  65%   │  ← 屏幕底部中央
└─────────────────────────────────────────────────────┘
   │   │              │                    │          │
   │   │              │                    │          └─ 进度百分比
   │   │              │                    └────────── 当前时间戳
   │   │              └──────────────────── 进度条滑块
   │   └─────────────────────────────────── 进度条轨道
   └──────────────────────────────────── 播放/暂停按钮
```

## 基本操作

### 1️⃣ 启动自动播放

```
操作：启用"交通态势"开关
结果：
  - 时间线控制条出现在屏幕底部
  - 播放按钮变为"⏸"（暂停）
  - 自动从0%开始播放
  - 每秒向前推进
```

### 2️⃣ 暂停播放

```
操作：点击"⏸"按钮
结果：
  - 动画暂停当前时刻
  - 按钮变为"▶"（播放）
  - 地图上显示保持当前时刻的交通态势
```

### 3️⃣ 恢复播放

```
操作：点击"▶"按钮
结果：
  - 从暂停位置继续播放
  - 按钮变为"⏸"（暂停）
  - 地图实时更新
```

### 4️⃣ 手动拖动进度条

```
操作：
  a) 点击进度条任意位置
  OR
  b) 拖动圆形滑块

结果：
  - 自动暂停动画播放
  - 地图立即显示对应时刻的交通态势
  - 时间戳和百分比实时更新
  - 继续拖动可以精确浏览不同时刻
```

### 5️⃣ 关闭交通态势

```
操作：关闭"交通态势"开关
结果：
  - 时间线控制条消失
  - 所有交通实体被清除
  - 地图恢复到普通显示
```

## 交互示例

### 示例 1：查看上午高峰期

1. 启用交通态势分析
2. 点击暂停按钮 ⏸
3. 拖动进度条到约30%位置
4. 查看对应的上午10点左右的交通态势
5. 微调滑块找到最感兴趣的时刻

### 示例 2：观察全天交通变化

1. 启用交通态势分析
2. 让动画自动播放（约96秒看完全天24小时）
3. 观察颜色从绿→黄→橙→红的动态变化
4. 发现高峰期和低谷期的变化规律

### 示例 3：对比两个时刻

1. 启用交通态势分析，暂停在时刻A（如上午8点）
2. 观察并记住交通情况
3. 拖动进度条到时刻B（如下午2点）
4. 对比两个时刻的交通差异

## 键盘快捷键

| `←` `→` | 微调时间         | 进度条有焦点 |

## 常见问题

### Q: 拖动进度条时地图不动怎么办？

**A**: 检查是否有数据加载错误：

-   打开浏览器DevTools查看Console
-   搜索 `[Traffic]` 关键词查看日志
-   确保 `/public/data/road_network_with_speeds.geojson` 文件存在

### Q: 动画播放很卡怎么办？

**A**: 尝试以下方案：

1. 增加更新间隔时间：`TRAFFIC_UPDATE_INTERVAL = 2000`
2. 降低Cesium的渲染质量
3. 检查浏览器硬件加速是否启用

### Q: 时间戳显示位置移动设备上看不清？

**A**: 这是响应式设计的预期行为。在宽度<480px时会隐藏时间戳文本以节省空间。

### Q: 如何跳回到最开始？

**A**: 拖动进度条到最左边，或按 `Home` 键（进度条有焦点时）

## 性能提示

-   **最佳体验**：在现代桌面浏览器中，使用Chrome/Firefox
-   **移动设备**：可能会有轻微延迟，但仍可正常操作
-   **大屏优化**：在超大屏上（>2560px）时间线控制条宽度会更大

## 自定义样式

如果想修改时间线控制条的外观，编辑 `RoadVisual.vue` 中的 `<style scoped>` 部分：

```scss
/* 修改位置和距离 */
.traffic-timeline-control {
    bottom: 20px; // 改为 50px 会更高
    left: 50%;
}

/* 修改按钮颜色 */
.play-btn {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    // 改为自己喜欢的颜色
}

/* 修改进度条颜色 */
.timeline-slider {
    background: linear-gradient(to right, #667eea 0%, #764ba2 100%);
}
```
